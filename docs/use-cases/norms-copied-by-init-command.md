# 文書管理の規範を、初期化のコマンドで適用先の製品へ複製する

> **棄却**: この提案は採らない。文書管理の規範は mitodoke のリポジトリ自身が `quality` の item として持ち、
> 適用先の製品は規範を自分のグラフへ写さず、mitodoke の文書として参照する。決定は
> [規範は mitodoke のリポジトリ自身で管理し、適用先は写さず参照する](../adr/norms-kept-in-own-repository.md)
> にあり、この提案はその棄却した代替案に当たる。

## 提案した使われ方

利用者は自分の製品に mitodoke を導入するときに、初期化のコマンドを実行する。コマンドは mitodoke の
文書管理の規範を雛形の item として、適用先の製品のグラフへ複製する。利用者は複製した規範の item を
自分の製品の item として持ち、必要に応じて書き換える。

## 作らない理由

規範を適用先の製品へ複製すると、mitodoke のバージョンを上げたときに、適用先の写しが古いまま残る。
mitodoke 自身が規範を item として持てば、規範を含めた実際のグラフで CLI を確かめられる。規範のうち機械で
確かめられるものは CLI の検査が確かめ、残りは mitodoke の文書として読まれるので、適用先の製品のグラフが
規範の item を持たなくてよい。

## 出典

根拠の決定は次の ADR が持つ。

- [規範は mitodoke のリポジトリ自身で管理し、適用先は写さず参照する](../adr/norms-kept-in-own-repository.md)
