# 型と置き場所の一致を構造の契約にし、型ごとの置き場所を設定に持つ

- ステータス: stable
- 日付: 2026-11-17
- 関連: GitHub Issue #4
- 起点: 2026-11-17 の grilling（Q36）で確定

## 背景

mitodoke へ写した文書管理の仕組みには、未解決のまま残っていた論点がある。item の型と置き場所の
一致は確かめておらず、起票のスクリプトも置き場所を型と比べていない。`docs/test/` の外に置いた
test_case を見つける手段も無い。どちらも、いまの違反は 0 件である。

mitodoke を製品にするにあたり、この論点を製品で扱うかを決めなければならない。

## 決定

型と置き場所の一致を構造の契約に加える。

- 型ごとの置き場所を設定に持つ
- `mitodoke index` の見出しも、同じ表から決める
- `docs/test/` の外に置いた test_case も、この一致で見つける

## 根拠

index の見出しを型ごとに決めるために、独自の型も含めた型ごとの置き場所は、どのみち設定に書く
ことになる。その表があれば、型と置き場所の一致を確かめる手間は小さく、`mitodoke index` の見出しも
同じ表から決まる。型と置き場所の取り違えを見つけられ、`docs/test/` の外の test_case もこの一致で
見つかる。

## 棄却した代替案

### 製品では扱わず、必要になったら個別に起票する

型と置き場所の一致を構造の契約にせず、必要になったときに個別の Issue で扱う案。型ごとの置き場所の
表はどのみち設定に書くので、一致を確かめる手間は小さい。扱わずにおくと、型と置き場所の取り違えと
`docs/test/` の外の test_case を見つけられないまま残る。
