# user

## Definition

A person who uses the product. A user need not read the repository that builds it, and
observes only the product's behavior and contracts. What a user wants to do with the
product is stated by a use case.

## Avoid

- ユーザー: a katakana spelling. Write 利用者.

## 定義

製品を使う人。製品を作るリポジトリを読むとは限らず、観測するのは製品の振る舞いと契約だけ
である。利用者が製品で何をしたいかは要求が述べる。

## 避ける表現

- ユーザー: カタカナの表記。利用者と書く。
