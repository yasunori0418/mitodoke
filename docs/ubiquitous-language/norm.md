# norm

## Definition

A collective name for the items of the three types `requirement`, `quality` and
`test_plan`, each of which states a rule that binds something. The type a norm goes in is
decided by whom it binds: the product as its users see it goes in a `requirement`, the
people and process that build the product go in a `quality`, and what is tested and how
goes in a `test_plan`.

## 定義

`requirement`・`quality`・`test_plan` の 3 型の item の総称。どれも何かを縛る規則を述べる。
どの型に置くかは、それが誰を縛るかで決める。利用者から見える製品を縛るものは
`requirement`、製品を作る人と進め方を縛るものは `quality`、何をどうテストするかを縛るものは
`test_plan` に置く。
