# silence

## Definition

The property of a threat of whether anyone can notice it when it happens. Silence is not
an axis for scoring a risk; it is written in the body of each risk as prose, so the
information is kept without becoming part of the score.

## Avoid

- 気付かれにくさ: names only one end of the property, as an everyday phrase. Write 沈黙性.

## 定義

脅威が起きたときに、それに気付けるかどうかという性質。リスクを採点する軸にはせず、各リスクの
本文に散文で書く。こうすると情報は失われず、スコアの一部にもならない。

## 避ける表現

- 気付かれにくさ: 性質の片方の端だけを指す日常的な言い回し。沈黙性と書く。
