# test asset

## Definition

A file or other resource of implemented test code that a test case corresponds to. A test
case and its test asset correspond one to one, which links the intent written in the
document graph with its implementation. The correspondence shows where a test is
implemented; it does not prove that the test is correct or that it detects the defect it
aims at.

## 定義

テストケースに対応する、実装されたテストのコードのファイルやリソース。テストケースと
テスト資産は一対一で対応し、ドキュメントグラフに書いたテストの意図と、その実装を結ぶ。
この対応はテストがどこに実装されているかを示すが、テストが正しいことや、狙った欠陥を
検出できることまでは示さない。
