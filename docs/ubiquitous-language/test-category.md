# test category

## Definition

A division of a product's tests that the product itself decides by configuration, as a
single list. The directories in which test conditions and test cases are placed, the
values of a risk's `section` and the headings of the index for each category are all
derived from that list. The content of the list differs from product to product.

## 定義

製品のテストを分ける単位で、製品が自分で、設定の 1 つの一覧として決めるもの。テスト条件と
テストケースを置くディレクトリ、リスクの `section` の値、区分ごとの索引の見出しは、すべてこ
の一覧から導く。一覧の中身は製品ごとに違う。
